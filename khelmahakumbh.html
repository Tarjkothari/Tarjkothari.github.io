About the Project

This project was developed during the SSIP Hackathon, tackling a specific problem statement provided by the Government of Gujarat. Working under tight deadlines, the primary focus was on delivering a robust and optimized web solution.

Key Achievements
  • High-Performance Infrastructure: Successfully made the server incredibly fast and reliable to handle potential spikes in traffic.
  • Rapid Team Coordination: Acted as the Team Leader for a large group of 8 developers, effectively distributing tasks and merging code over an intensive 2-week period.
  • Integrated Tech Stack: Leveraged PHP and JavaScript to build a fully functional prototype from the ground up.
